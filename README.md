# Neovim config

Neovim 1.12 configuration built step by step from scrath with lazy.nvim

# Layout

- 'init.lua'       - entry point
- 'lua/config/'    - core settings 
- 'lua/plugins/'   - one plugins spec file per concern
- 'lazy-lock.json' - pinned plugin versions

# Requirements

Neovim 1.12+, git, C compiler, ripgrep, fd,  tree-sitter-cli, Node.js and a Nerd Font.
